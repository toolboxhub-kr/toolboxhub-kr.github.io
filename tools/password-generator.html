🔐 강력한 비밀번호 생성기 & 보안 강도 측정기

암호학적으로 안전한 난수(Web Crypto API)로 해킹 걱정 없는 비밀번호를 1초 만에 생성하세요.

보안 강도: - 엔트로피: 0 bits
추가 후보 비밀번호 5개 (클릭하여 복사)

비밀번호 엔트로피(보안 강도) 계산 원리

비밀번호의 안전성은 문자 집합 크기(Pool Size, $N$)와 길이($L$)에 의해 결정되는 정보 엔트로피(bits)로 측정합니다.

엔트로피(bits) = 길이(L) × log₂(사용 가능한 문자 수 N)
예) 대소문자+숫자+특수문자(약 86자)로 16자리 생성 시 ≈ 102.8 bits (현존 컴퓨터로 해독 불가)

계정 보안 관리 실전 팁

💡 사이트마다 다른 비밀번호 사용: 아무리 복잡한 비밀번호라도 여러 사이트에 돌려 쓰면 한 곳에서 유출될 때 모든 계정이 위험해집니다. 크롬·애플 키체인·Bitwarden 같은 비밀번호 관리자에 자동 저장해 두세요.

자주 묻는 질문 (FAQ)

생성된 비밀번호가 서버로 전송되거나 저장되나요?
절대 저장되지 않습니다. 브라우저 내부의 Web Crypto API로만 생성되며 새로고침하면 메모리에서 즉시 사라집니다.
Math.random() 대신 Web Crypto API를 쓰는 이유는 무엇인가요?
일반 Math.random()은 예측 가능한 의사난수이지만, crypto.getRandomValues()는 운영체제의 암호학적 난수 생성기(CSPRNG)를 사용해 예측이 불가능합니다.
특수문자를 허용하지 않는 웹사이트에서는 어떻게 하나요?
특수문자 체크를 해제하는 대신 비밀번호 길이를 16~20자리로 조금 더 늘리면 특수문자 없이도 매우 높은 보안 강도를 유지할 수 있습니다.
